About This Project

A comprehensive Angular Task Manager demonstrating modern development practices

🎯 Project Overview

This Task Manager application is built to showcase key Angular concepts including component communication, custom pipes, routing with lazy loading, and reusable UI components. It follows best practices with standalone components and modern Angular architecture.
