2. FIREBASE FIRESTORE INTEGRATION
--------------------------------------------------------------------------------

Feature: Firestore as Real-Time Database
- Store tasks in Firestore collections
- Structure: users/{userId}/tasks/{taskId}
- Real-time sync between app and Firestore
- Offline persistence built-in
- Automatic conflict resolution

Firestore Structure:
Collections:
  - users (collection)
    - {userId} (document)
      - email: string
      - displayName: string
      - createdAt: timestamp
      - lastLogin: timestamp
      - settings: object
      - tasks (subcollection)
        - {taskId} (document)
          - title: string
          - description: string
          - priority: 'low' | 'medium' | 'high'
          - completed: boolean
          - createdAt: timestamp
          - updatedAt: timestamp

Operations:
- CREATE: Add document to tasks subcollection
- READ: Query user's tasks collection
- UPDATE: Update task document
- DELETE: Delete task document
- REAL-TIME: Auto-update UI when data changes

Technical Requirements:
- Firebase Firestore SDK
- Security rules to ensure users only access their own data
- Firestore queries for filtering and sorting
- Offline persistence enabled
- Optimistic updates for better UX
- Real-time listeners for live updates

7. FIREBASE SECURITY RULES
--------------------------------------------------------------------------------

Firestore Rules (ensures users can only access their own data):
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      
      match /tasks/{taskId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```
